# WhatsApp Proxy Manager — Releases

Публичный репозиторий **только с артефактами релизов** приложения
[WhatsApp Proxy Manager]. Исходный код — в отдельном приватном репозитории.

В релизе с тегом `latest` публикуются:

- `version-macos-arm64.json` — манифест обновления (`{version, sha, dmg}`);
- `WhatsApp Proxy Manager-<version>-arm64.dmg` — образ приложения.

Клиент приложения читает манифест, сравнивает версии, качает DMG, сверяет SHA-256
и атомарно обновляется. Токен для чтения не нужен — репозиторий публичный.
